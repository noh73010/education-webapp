# 학습 홈 광고 운영

물류관리사 `/missions/` 맨 아래와 공인중개사 `/realtor/` 맨 아래에만 수동형 AdSense 광고를 각 1개 표시한다. 문제 풀이, 이론, 오답 복습, 모의고사, 결과, 로그인·계정 화면에는 광고 코드가 없다. 공인중개사 과목을 고른 뒤 방문하는 `/missions/`에도 광고를 넣지 않는다. 자동 광고(Auto ads)는 사용하지 않는다.

기본값은 꺼짐이다. 계정 승인 전이나 설정이 비어 있을 때 광고 스크립트와 빈 광고 상자가 출력되지 않는다. 시작하려면 Google AdSense에서 사이트 승인을 받고, 표시 광고 단위를 2개 만든 뒤 Render 웹 서비스 환경변수에 다음을 설정한다.

AdSense 사이트 소유권 확인에는 광고 스크립트 대신 공통 `<head>`의 `google-adsense-account` 메타 태그를 사용한다. 이 태그는 광고를 요청하지 않으며, 게시자 ID는 비밀값이 아니다. 사이트 심사 요청은 배포된 메타 태그를 확인한 뒤 진행한다.

```text
DJANGO_ADSENSE_CLIENT_ID=ca-pub-<발급된 16자리 ID>
DJANGO_ADSENSE_LOGISTICS_HOME_SLOT=<물류관리사 홈 광고 단위 ID>
DJANGO_ADSENSE_REALTOR_HOME_SLOT=<공인중개사 홈 광고 단위 ID>
DJANGO_ADSENSE_ENABLED=1
```

광고를 켜기 전 실제 문항·이미지의 이용 권리와 사이트의 광고 정책 적합성을 점검한다. 광고·쿠키·제3자 제공자에 관한 개인정보처리방침도 실제 처리 방식에 맞춰 공개해야 한다. 현재 코드만으로 AdSense 승인이나 개인정보 관련 의무 이행이 완료되는 것은 아니다. 필요하면 `DJANGO_ADSENSE_ENABLED=0`으로 즉시 중단할 수 있다.

광고는 `광고`로 표시하고 주요 학습 버튼과 거리를 둔다. 모바일에서 광고 로딩으로 화면이 흔들리지 않게 최소 공간을 확보한다. 운영자는 배포 후 실제 광고 노출, 모바일 레이아웃, 학습 시작률과 이탈률을 확인하고 불편이 생기면 중단한다. Google 설정에서 Auto ads를 켜면 코드가 들어간 페이지에 수동 광고 외 광고가 추가될 수 있으므로 끈 상태를 확인한다.

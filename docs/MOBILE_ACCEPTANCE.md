# 모바일 출시 전 확인

## 검증 범위와 현재 상태 (2026-09-04)

개발 자동 테스트와 실제 휴대폰 검증은 구분한다. 로컬 393×883 브라우저에서
모의고사 재개 → 선택 → 새로고침 후 선택 복원 → 제출 → 다음 문항 → 결과를 확인했다.
실제 Samsung Internet/Android Chrome/iPhone Safari의 절전·앱 종료·네트워크 전환은 미검증이다.
실제 회원 데이터가 아닌 테스트 계정에서 수행한다. 운영 데이터 초기화를 테스트 용도로 하지 않는다.

## 기기별 수행표

아래 항목은 기기명, OS/브라우저 버전, URL, 발생 시각, 성공/실패를 함께 기록한다.

| 시나리오 | 기대 결과 |
| --- | --- |
| 첫 방문 → 출발점 → 진단 3문제 | 오답/해설 확인 후 다음 문제, 실제 응답 범위만 요약 |
| 일반 문제 답 선택 → 저장 안내 → 새로고침 | 선택 복원, 채점/Attempt 증가 없음 |
| 홈으로 이동 → 풀던 문제 이어하기 | 임시저장 답안 복원 |
| 답 선택 → 비행기 모드 → 제출 | 미제출 안내, 연결 후 재시도 가능 |
| 제출 직후 연결 끊김 → 연결 후 제출 여부 확인 | 저장되었다면 기존 결과, 아니라면 재제출; 중복 기록 없음 |
| 빠른 연속 제출 / 뒤로 가기 후 재제출 | 동일 제출 1회만 기록 |
| 모의고사 선택 → 앱 전환 1분 → 복귀 | 선택 유지, 남은 시간은 1분 감소 |
| 모의고사 브라우저 종료 → 다시 시험 시작 | 무료 일일 한도에 막히지 않고 풀던 시험 재개 |
| 모의고사 만료 중 오프라인 → 연결 | 서버 기준 종료, 만료 뒤 답안 불인정, 결과 중복 반영 없음 |
| 시험 결과 새로고침 | 점수/기록 변화 없음, 한글 정상, 합격 확률 표시 없음 |
| 문제 이미지 확대 → 닫기 | 답안 유지, 제출 버튼/하단 메뉴 가림 없음 |
| 반복 오답 개념 비교 | 검수된 연결이 있는 경우만 비교 자료 및 다른 문제 제공 |

브라우저를 완전히 종료하면 서버 저장 전 탭 답안은 잃을 수 있다.
sessionStorage는 같은 탭의 보조 수단이며 완전한 오프라인 학습을 보장하지 않는다.
SQLite에서는 동시 쓰기 시 잠금 오류가 날 수 있다. PostgreSQL 운영 동시성은 별도 검증한다.

## 콘텐츠 검수 및 배포

Windows (프로젝트 루트):

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test core.tests
.\.venv\Scripts\python.exe manage.py audit_learning_content --subject-code logistics
git diff --check
```

배포는 별도 승인 후 DB 백업 → migrate → 필요한 정적 파일 배포 → 콘텐츠 검수 overlay 적용 →
테스트 계정 smoke test 순서로 한다. 이번 작업에서 운영 서버 배포는 수행하지 않았다.
수동 검토한 정확한 텍스트에만 아래 명령으로 자료/보류를 적용한다.

```powershell
.\.venv\Scripts\python.exe manage.py audit_learning_content --subject-code logistics --apply-reviewed
```

일반 audit는 읽기 전용이다. `--apply-reviewed`만 DB를 변경한다.
import_missions도 같은 검수 overlay를 적용하므로 재수입이 보류를 임의로 해제하지 않는다.
보류 해제는 원본 복원과 검수 후 manifest 항목을 갱신하고 is_usable_for_set도 명시적으로 확인한다.

실제 로컬 DB: 270문항, 내용 검토 6문항/개념 비교 3묶음, 원출처 미확인 270문항,
내용 검수 대기 264문항, 자동 출제 보류 2문항. 이미지의 지문을 사람이 대조해야 할 문항 14개.
CSV 전체 재수입 테스트 데이터 수와 현재 로컬 DB 수는 다르며, 이번에 미수입 문제를 추가하지 않았다.

- `LOGISTICS-LM01-LOGISTICS-28-1-0001`: 7R 구성에 대한 정답/해설 원본 대조 필요.
- `LOGISTICS-IT01-LOGISTICS-29-1-0120`: ㄱ·ㄴ·ㄷ·ㄹ·ㅁ 판단 지문과 이미지 없음.

보류는 문제 삭제가 아니다. 기존 풀이 기록/기존 생성된 시험은 보존하며,
새 자동 출제에서 제외한다. 직접 문제 링크에는 검토 중 경고가 표시된다.
문제 원출처는 참고 개념 자료와 다르므로 제공되지 않은 기출 원출처를 만들어 입력하지 않는다.

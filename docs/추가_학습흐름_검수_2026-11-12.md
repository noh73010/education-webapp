## 발견하여 수정한 항목

1. **맛보기 탭 간 체험 혼선**: 다른 탭에서 체험을 재시작해도 이전 화면의 문제 순번이 같으면 새 체험의 답안이나 확신도를 바꿀 수 있었다. 답안 제출·확신도·다음 문제·회원 기록 저장에 체험 식별자를 함께 보내고 현재 체험과 다르면 409로 거부한다. 이전 화면은 현재 체험으로 복귀하도록 안내하며, 비동기 선택도 성공으로 표시하지 않는다. 배포 이전에 열린 폼은 새로고침해야 한다. 이는 체험을 구별하는 보호이며 모든 동시 세션 쓰기의 직렬화를 보장하는 것은 아니다.
2. **저장 응답 지연 시 진행 버튼 잠김**: 맛보기 확신도 저장이 응답 없이 지속되면 버튼이 계속 비활성화될 수 있었다. 12초 제한과 재시도 안내를 추가했다. 응답을 확인하기 전에는 저장 성공으로 표시하지 않는다. 재시도는 같은 체험의 기존 항목을 갱신한다.
3. **복습 시점이 지난 정답 누락**: 수동 복습 목록이 오답·확신 부족만 선택하여, 정답 후 정착 복습 시점 또는 숙련 후 재확인 시점에 도달한 문항을 놓치고 있었다. 복습 시점에 도달한 정답도 포함하며 아직 복습할 때가 아닌 정답·숙련 문항은 제외한다. 사용자가 직접 선택하는 오답 복습은 시점 전에도 가능하다.
4. **학습 범위 이동**: 챕터를 선택한 상태에서 상단 새 문제/복습/다시 보기 버튼을 누르면 전체 범위로 바뀌었다. 세 버튼에 과목·챕터 범위를 유지하고, 새 문제 종료 후 복습도 같은 과목으로 연결했다. 다른 챕터 선택은 계속 가능하다.

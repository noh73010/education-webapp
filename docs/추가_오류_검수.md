# 추가 오류 검수

수험생의 선택 → 제출 → 피드백 → 재풀이 → 복습, 맛보기 → 로그인/회원가입, 모의고사 → 학습 기록, 학습 초기화의 연결을 검수했다.

## 재현 후 수정한 사항

| 영역 | 확인한 문제 | 수정 결과 |
| --- | --- | --- |
| 학습 초기화 | 해설 열람 및 ‘아는 문제’ 기록이 삭제 대상에서 빠져 초기화 후에도 새 문제·추천에 영향을 줌 | 전체/자격증별 초기화에 열람 기록 포함. 다른 사용자·다른 자격증 기록은 유지 |
| 모의고사 학습 반영 | 오답인데도 기존 ‘아는 문제’ 제외 기간이 남음. 일반 풀이와 달리 독립적인 풀이 증거를 기록하지 않음 | 오답 시 제외 기간 해제. 최근 24시간 해설 열람 여부에 따라 학습 증거를 기록하고 중복 반영 방지 유지 |
| 이전 화면의 오답 원인 폼 | 다시 푼 뒤에도 과거 풀이의 원인을 저장할 수 있었음 | 최신 유효 풀이만 수정 허용. 무효화된 과거 풀이도 수정 차단 |
| 맛보기 이전 화면 | 이전 문제의 확신도 저장 요청이 현재 문제에 적용될 수 있었음 | 요청의 문제 순서와 현재 순서가 같은 경우만 저장 |
| 출제 중지 문제 | 일반 풀이의 오래된 화면이나 직접 주소로 제출하면 새 기록 생성 가능 | 일반 풀이 POST 차단 및 입력 폼 숨김. 기존 이력은 보존 |
| 맛보기 회원가입 연결 | 로그인에서 회원가입으로 이동하면 결과 복귀 주소가 사라짐 | 가입·오류 재입력·소셜 로그인 버튼에 내부 복귀 주소 유지. 외부 주소는 거부 |
| 모바일 서비스 소개 | 3번째 단계의 화살표가 일반 흐름 요소로 표시되어 가로 넘침 발생 | 모바일 화살표의 위치·크기를 명시하여 넘침 제거 |

수정 전 재현 테스트 7개 중 6개가 실패했고 수정 후 모두 통과했다. 독립적인 정답 증거·무효 이력 보호·회원가입 복귀/외부 주소 차단 테스트도 추가했다.

## 검증한 범위

- 자동 테스트 398개 통과: 접근 권한, 중복 제출, 시험 제한 시간, 답안 변경/복원, 기록 초기화, CSV 반영 등의 기존 테스트 포함.
- 현재 16개 CSV 검증 및 1,400문항의 표시 원문 보존 검사 통과. 이미지 경로의 파일 존재 검사 포함.
- 로컬 주요 12개 화면 × 모바일 390px/PC 1280px = 24개 화면 조합: 정상 응답, 가로 넘침 및 브라우저 JavaScript 오류 없음.
- 로그인 화면 → 회원가입 화면의 맛보기 복귀 주소 유지 확인.
- 운영 공개 페이지 응답, 비로그인 보호 페이지의 로그인 이동, 최근 오류 로그 확인.
- 데이터베이스 스키마 변경 없음. 실제 회원의 기록 초기화·탈퇴는 실행하지 않음.

## 다음 실사용 검수 우선순위

1. **문제 내용**: 정답·해설·이미지 수치 대조, 특히 법령/세율의 기준일. CSV 구조 검증이나 표시 원문 보존 검사는 내용의 정오를 보증하지 않는다.
2. **CSV 교체와 동시 응시**: 진행 중인 모의고사에서 문제·보기·정답이 교체되는 상황의 문항 버전 고정과 기존 답안 처리. 이번 검증만으로 이 경로의 안전성을 확정하지 않는다.
3. **실제 소셜 로그인**: 네이버·카카오·Google 계정의 동의 거부/재로그인/가입 후 결과 복귀. 설정·로컬 테스트를 실제 제공자의 인증 완료와 동일하게 취급하지 않는다.
4. **실제 기기와 장시간 사용**: Galaxy 기본 브라우저/iPhone Safari에서 앱 전환, 뒤로 가기, 장시간 시험, 네트워크 단절 후 복구. Chromium 화면 검사를 실제 기기 검증과 동일하게 취급하지 않는다.
5. **사용량 증가**: 긴 풀이 이력을 가진 계정 및 여러 기기의 동시 제출, 동시 접속 부하와 운영 DB 응답 시간. 로컬 소량 이력의 응답 측정으로 운영 부하 한계를 추정하지 않는다.

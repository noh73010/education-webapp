## 발견·수정

### 1. 시험 도중 문항이 바뀌면 최신 정답으로 채점되던 경로

`ExamSessionMission.question_snapshot`에 시험 시작 당시의 질문·보기·정답·해설·이미지 경로와 학습 개정을 저장한다. 일반 생성/짧은 시험/과목 시험/2교시 대기 문항 모두 같은 방식으로 고정한다.

- 채점과 응시 당시 해설은 고정된 내용으로 처리한다.
- 의미/정답이 개정된 문항의 옛 답안은 시험 점수만 유지하고 현재 학습 통계에서는 제외한다.
- CSV의 `수정유형=오타`는 학습 개정을 올리지 않아 풀이 기록의 유효성을 유지한다. 정답 변경은 오타로 표시해도 개정된다.
- 옛 무효 답안이 있다는 이유로 새 버전의 정상 모의고사까지 준비도에서 영구 제외되던 경로도 수정했다.
- 결과/오답 목록에는 응시 당시 문항을 보는 전용 화면을 연결했다. 시험이 끝나기 전이나 다른 회원에게는 해설을 공개하지 않는다.
- 마이그레이션은 진행/대기 중인 기존 시험을 배포 시점 데이터로 고정한다. DB 기본값과 CSV 변경 전 고정 처리를 넣어 구 프로세스의 쓰기와 호환한다.
- 이미지 **경로**를 보관한다. 과거 이미지 파일을 같은 경로에서 덮어쓰거나 삭제하면 과거 이미지 자체를 복원할 수는 없으므로, 이미지는 새 파일명으로 추가하고 과거 파일을 유지해야 한다.

### 2. 국가물류정책위원회 문항의 법령 오류

문항 `LOGISTICS-LR01-LOGISTICS-29-2-0043`은 ‘국토교통부장관이 위원장’인 보기를 틀렸다고 처리하면서 해설을 국무총리로 적고 있었다. 물류정책기본법 제18조 제2항과 대조해 틀린 보기 1번을 ‘국무총리’로 바꾸고 해설을 국토교통부장관으로 바로잡았다. 단순 오타가 아닌 의미 변경으로 처리한다.

대조 자료:

- [국가법령정보센터 물류정책기본법, 시행 2022-12-11](https://www.law.go.kr/LSW/lsInfoP.do?efYd=20221211&lsiSeq=243099)
- [국가법령정보센터 물류정책기본법 연혁](https://law.go.kr/LSW/lsInfoP.do?lsiSeq=258207)
- [관세청 관세법 제213~220조](https://unipass.customs.go.kr/clip/lworsrch/openULS0101032Q.do?lworAdmnRulNo=001556&lworUtNoEd=220&lworUtNoSt=213)
- [국세청 종합부동산세 개요](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7738&mi=2351)

해설 첫 정답 번호 불일치와 동일 보기 중복은 앞으로 CSV 검증에서 차단한다. 자동 번호 대조만으로는 위원장 오류처럼 지식 자체가 잘못된 문항을 검출할 수 없다. 짧은 해설이나 같은 질문 문장은 자동으로 오답 판정하지 않았다. 동일 질문 문장 10그룹은 보기가 서로 달라 완전 중복으로 처리하지 않았다.

이미지 OCR에서 내용이 잡히지 않은 8개는 직접 열어 확인했다. 손익분기점 2,400/3,000개, 운송 손익분기 거리 180km, CO₂ 감소 24,000kg, EOQ 관련 비용 240만원/주문 30회, 최대유량 13, BUC 운임 US$11,500을 원자료와 재계산 대조했다. DAP/DPU 그림과 A등급 도해도 확인했다. 이 8개의 읽기 실패는 이미지 누락이 아니었다.

### 3. 소셜 로그인 취소 후 맛보기 복귀 주소 소실

취소 시 기본 안내 페이지로 이동하면서 결과 복귀 주소가 사라지던 경로를 수정했다. 신뢰할 수 있는 OAuth state의 내부 주소만 유지해 로그인으로 돌아가며, 취소 안내를 표시한다. 외부 주소와 재사용 state는 거부한다. 인증 오류의 내부 정보나 토큰을 화면에 노출하지 않는다.

실제 계정 인증 완료는 대체 응답 통합 테스트와 구분한다. 운영에 테스트 회원을 새로 만들지 않았다.

### 4. 서로 다른 탭/기기의 임시 답안 덮어쓰기

답안 저장/제출 요청에 수정 시점을 포함한다. 같은 문제의 최신 임시 답안이 다른 탭·기기에서 바뀌면 409로 차단하고 새로고침을 안내한다. 동일 내용의 통신 재시도는 허용하고, 이미 제출된 동일 토큰은 기존 결과로 이동시킨다.

브라우저 로컬 답안도 서버의 기준 시점이 같은 경우만 자동 복원한다. 단순 기기 시계 차이로 오래된 답을 덮어쓰지 않게 한다. 앱을 벗어날 때에는 임시 저장을 바로 시도하고, 오프라인 최종 제출 실패가 확인창 뒤에 가려지지 않도록 했다. 통신 실패 재시도와 명시적 제출 동작을 함께 확인했다.

기존 클라이언트 호환 경로는 유지하므로 배포 전에 열어둔 화면은 새로고침해야 새 보호 코드가 적용된다.

## 실제 기기에서 남은 확인 순서

1. 기존 화면을 새로고침한 뒤 5문제를 풀고 네이버 또는 Google 로그인으로 결과에 복귀한다. 취소 후 다시 로그인하는 경우도 확인한다.
2. 문제의 답을 선택하고 인터넷을 끊어 답을 바꾼다. 연결을 복구한 뒤 새로고침/뒤로 가기를 해도 선택이 유지되는지 본다.
3. 모의고사 중 다른 앱으로 이동했다가 돌아와 남은 시간·선택 답안이 유지되는지 확인한다. 오프라인에서 최종 제출을 누르면 채점되지 않아야 한다.

실제 계정 추가 인증 및 실제 기기의 OS 동작은 자동 환경에서 완료했다고 표시하지 않는다.

# 공인중개사 문제 등록

## 저장 위치

- CSV: 프로젝트 루트 `generated/realtor/` (예: `realtor_35-1-1.csv`)
- 문제 이미지: `core/static/images/questions/realtor/` (선택 사항)

현재 등록된 기출 변형 CSV는 6개, 총 400문항입니다. 이미지 24개도 함께 등록되어 있습니다.

| 파일 | 의미 | 문항 수 |
| --- | --- | ---: |
| `realtor_35-1-1.csv` | 제35회 1차 기출 변형 | 80 |
| `realtor_35-2-1.csv` | 제35회 2차 1교시 기출 변형 | 80 |
| `realtor_35-2-2.csv` | 제35회 2차 2교시 기출 변형 | 40 |
| `realtor_36-1-1.csv` | 제36회 1차 기출 변형 | 80 |
| `realtor_36-2-1.csv` | 제36회 2차 1교시 기출 변형 | 80 |
| `realtor_36-2-2.csv` | 제36회 2차 2교시 기출 변형 | 40 |

파일 이름의 `35-1-1`은 35회 1차, `35-2-1`은 35회 2차 1교시를 뜻합니다. 파일 이름에 회차·단계가 있으면 가져오기 명령이 문항 출처에 `기출 변형`과 해당 회차·교시를 기록합니다. CSV에 출처를 명시한 경우에는 그 값을 우선합니다. 아직 추가하지 않은 회차·교시는 반영되지 않습니다.

물류관리사 파일과 섞지 않습니다. 같은 사용자라도 `Subject`가 다르므로 풀이·오답 기록은 자격증별로 분리됩니다.

## CSV 형식

기존 `import_missions`가 받는 한국어 열 형식을 그대로 사용합니다. UTF-8 CSV로 저장하세요.

필수 열: `번호,과목,챕터,난이도,문제,보기1,보기2,보기3,보기4,보기5,정답,해설`

첫 줄 예시(실제 문제 아님):

```csv
번호,과목,챕터,난이도,문제,보기1,보기2,보기3,보기4,보기5,정답,해설,문제이미지,문제구분,출처,검수일
1,부동산학개론,RE01-01 부동산학 총론,중,검수한 문제 지문을 입력,선택지 A,선택지 B,선택지 C,선택지 D,선택지 E,2,정답 근거와 오답 이유를 입력,,출처 미등록,,
```

예시는 형식 설명용이며 실제로 가져오지 마세요. 새 파일의 `과목`은 가능하면 다음 표준 이름을 씁니다.

1. `부동산학개론`
2. `민법 및 민사특별법`
3. `공인중개사법령 및 중개실무`
4. `부동산공법`
5. `부동산공시법 및 부동산세법`

`챕터`는 **`RE01-01 부동산학 총론`**처럼 `RE` + 학습 영역 2자리 + `-` + 단원 2자리 + 단원명으로 씁니다. 등록된 단원 코드는 `core/services/realtor_curriculum.py`의 55개가 기준이며, 가져올 때 이 코드의 공식 단원명으로 정규화합니다. 코드에 맞지 않는 시험 과목명은 가져오지 않습니다. `난이도`는 `하/중/상`, `정답`은 `1`~`5`입니다. 다섯 보기 모두 필요합니다. 셀 안의 쉼표·줄바꿈은 CSV 따옴표 규칙에 맞게 저장합니다.

기존 35·36회 파일에서 쓰인 `민법 및 민사특별법 중 부동산 중개 관련 규정`, `부동산공법 중 부동산 중개 관련 규정`, `부동산공시법령`, `부동산세법`은 가져올 때 위 채점용 과목명으로 정규화합니다. 원본 CSV의 과목 표현은 바꾸지 않습니다.

학습 목차는 `RE01 부동산학개론` 10단원, `RE02 민법 및 민사특별법` 10단원, `RE03 공인중개사법령 및 중개실무` 9단원, `RE04 부동산공법` 10단원, `RE05 부동산공시법` 8단원, `RE06 부동산세법` 8단원으로 구성합니다. **RE05와 RE06은 화면에서 구분하지만 CSV `과목`에는 둘 다 `부동산공시법 및 부동산세법`을 입력**합니다. 시험·기록에서는 기존 한 과목 40문항 채점 구조를 유지합니다.

이론 원고를 추가할 때에는 `theory/realtor/RE01-01.md`처럼 단원 코드별 UTF-8 Markdown 파일을 둡니다. 원고가 없으면 이론 버튼을 열지 않고, 문제가 있으면 해당 단원의 문제 풀이만 제공합니다. 빈 예시 이론을 운영 화면에 표시하지 않습니다.

`번호`는 파일 안에서 고유하게 유지하고, 이미 가져온 문항의 파일명·번호는 바꾸지 마세요. 기존 문항을 수정하면 버전 관리가 적용되고 정답 변경은 과거 채점 기록을 무효화할 수 있습니다. 문항 삭제는 자동 동기화되지 않으므로 운영자 검토가 필요합니다. 안정적인 외부 ID를 직접 관리하려면 기존 영문 열 형식의 `external_id`를 사용할 수 있습니다.

법령 문항은 적용 법령·시행일과 근거 URL을 `출처`에 구체적으로 기록하고, 검수가 끝난 경우에만 `검수일`을 입력하세요. Q-Net 기출을 변형했더라도 이용 조건과 원문 출처를 별도로 확인해야 합니다. 이미지의 저작권도 별도 검토합니다.

현재 35·36회 원자료는 [Q-Net 제35회 문제지](https://www.q-net.or.kr/cst003.do?artlSeq=5214724&boardId=Q004&gId=08&gSite=L&id=cst00302&menuType=cst00309)와 [Q-Net 제36회 문제지](https://www.q-net.or.kr/cst003.do?artlSeq=5247125&boardId=Q004&gId=08&gSite=L&id=cst00302&menuType=cst00309)에서 확인할 수 있으며, 해당 게시물에는 공공누리 제1유형이 표시됩니다. 실제 변형 문항·이미지 각각의 정확성과 권리 검토는 별도로 유지해야 합니다.

이미지가 있으면 `문제이미지`에 `images/questions/realtor/파일명.png`처럼 정적 파일 경로를 입력합니다. 이미지가 없다면 비워 둡니다.

## 반영 방법

로컬에서 먼저 미리보기:

```powershell
py -3 manage.py migrate
py -3 manage.py sync_generated_missions --subject-code realtor --create-problem-sets --dry-run --fail-on-error
```

오류·출처·이미지 링크를 확인한 뒤 실제 반영:

```powershell
py -3 manage.py sync_generated_missions --subject-code realtor --create-problem-sets --fail-on-error
```

같은 CSV를 다시 실행해도 기존 `external_id`를 기준으로 갱신하며 중복 생성하지 않습니다. Render는 배포 시작 시 migration 후 `generated/realtor/`에 CSV가 있으면 동기화를 시도합니다. 파일별 오류는 로그로 남고 동기화 실패만으로 웹 서버 시작을 막지 않습니다. 출제 보류 문항은 기존 정책대로 제외합니다.

현재 공인중개사 화면은 1차·2차 선택과 과목별 진입을 제공합니다. 실전 모의고사는 시험 단계별 충분한 검수 문항과 별도 결과·합격 판정 구조가 준비될 때까지 열지 않습니다.

# 합격한걸음 유입 실험

기존 네이버 블로그 5편의 추적 링크는 유지한다. 아래 새 주소는 공개 콘텐츠용이며 기존 블로그 과목별 집계 링크가 아니다.

- 재주문점: https://passstep.onrender.com/study-examples/reorder-point/
- 건폐율과 용적률: https://passstep.onrender.com/study-examples/building-ratios/

## 커뮤니티 답변 초안

재주문점에서 자주 헷갈리는 건 하루 판매량과 입고를 기다리는 동안의 판매량을 구별하는 부분입니다. 하루 8개씩 팔리고 입고까지 3일이면 기다리는 동안 24개가 필요합니다. 안전재고가 10개라면 이 사례의 재주문점은 34개예요. 제가 만든 합격한걸음에 보기별 해설을 담은 무료 예제를 올려뒀습니다. 외부 링크가 허용되는 글이라면 위의 재주문점 주소를 덧붙입니다.

## 스터디 운영자 제안 초안

안녕하세요. 물류관리사 스터디에서 재고관리 복습용으로 써볼 수 있는 무료 문제를 만들었습니다. 먼저 재주문점 예제 한 문제를 함께 풀어보고, 이어지는 물류관리론 맛보기 5문제는 각자 풀어보는 방식입니다. 로그인 없이 정답과 해설까지 확인할 수 있습니다. 괜찮으시면 링크를 보내드리고, 설명이 모호한 부분이 있었는지도 듣고 싶습니다.

## 20초 풀이 영상 대본

- 0–5초: “하루에 8개, 입고까지 3일, 안전재고 10개. 몇 개 남았을 때 발주할까요?”
- 5–12초: “먼저 입고까지 팔릴 24개를 계산합니다. 안전재고 10개는 그다음에 더합니다.”
- 12–20초: “정답은 34개. 24개만 남겨 두면 예상보다 많이 팔릴 때 여유가 없어요. 같은 유형의 예제는 공개 해설에서 확인하세요.”

## 확인 순서

배포 후 비로그인 상태에서 두 공개 페이지와 과목별 시작 버튼을 확인한다. 검색 소유권이 확인된 계정에서 사이트맵을 제출하고 URL 색인 상태를 점검한다. 커뮤니티 규칙에 따라 실제 질문에 답하고, 스터디 운영자 연락은 대상을 정한 뒤 진행한다.

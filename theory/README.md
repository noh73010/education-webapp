# 챕터 이론 콘텐츠 관리

이 디렉터리는 처음 공부하는 사용자도 개념을 이해한 뒤 기존 기출문제로 넘어갈 수 있도록 자격증별 이론을 Markdown 파일로 관리합니다.

## 파일 규칙

```text
theory/
  <Subject.code>/
    <Mission.chapter_code>.md
```

예시:

```text
theory/logistics/LM01.md
theory/logistics/LW06.md
```

Subject와 Mission의 `course`, `chapter_code`, `chapter_name`을 등록하고 위 규칙에 맞는 파일을 추가하면 학습홈 로드맵에서 자동으로 이론 페이지가 활성화됩니다. 사용자 URL에는 내부 챕터 코드 대신 과목명과 챕터명으로 만든 읽기 쉬운 슬러그가 표시됩니다.

## 권장 문서 구조

```markdown
# 챕터 제목

## 먼저 이해하기

## 생활 속 사례

## 개념 비교

## 시험 핵심

## 암기 포인트

## 자주 틀리는 함정

## 개념 확인

### 확인 1
질문

정답: 정답과 간단한 이유

## 핵심 요약
```

연습문제는 같은 Subject와 `chapter_code`를 가진 기존 Mission을 자동으로 사용합니다. 별도의 문제를 Markdown에 작성하지 않습니다.

`정답:`으로 시작하는 문장은 사용자가 눌러 확인하는 접이식 해설로 렌더링됩니다. 정의만 나열하기보다 사례와 비교를 먼저 제시하고, 확인문제로 연습문제 진입 전에 이해 여부를 점검하는 구성을 권장합니다.

법규 콘텐츠는 시험 시행연도의 최신 법령과 출제기준을 확인한 뒤 갱신해야 합니다.
